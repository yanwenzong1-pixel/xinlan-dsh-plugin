## 二、设计规范（权威，执行时逐条对照）

### 1. 设计原则

1. 深色模式：固定悬浮控件一律黑底（半透黑/深色实底）+ 亮字，任意宿主页面（含白底）可读；
2. 玻璃质感只属于卡面：backdrop-filter 磨砂 + 顶部高光渐变 + 噪点肌理用于卡片/弹窗/任务瓷砖；列表容器不承担衬底（透明底，仅磨砂透出背后）；
3. 按钮语义清晰：可点击控件必须有明确填充色与文字对比；
4. 回退优先：颜色/圆角/模糊一律设计令牌变量（`var(--al-x, 字面量)`），变量失效仍兜底，永不落空、永不变白；
5. 确定性派生：等级/重要度/状态 → 色条/徽章色由打分阈值映射函数确定性派生，不依赖模型标签文案。

### 2. 设计令牌（单一来源，与 aero.ts 完全一致；表内不可再改，如需新令牌须先在 aero.ts 增补且带兜底）

| bgDeep | `#090C11` | 深层背景（遮罩/代码块/标题栏实底） |
| accent | `#88DD44` | 荧光酸绿（进度条/状态指示/滑块/高亮数值/状态标签） |
| info | `#64B5F6` | 信息冰蓝（运行中/已加载） |
| violet | `#9388FF` | 淡紫蓝（选中激活/高亮区块） |
| warn | `#FFC145` | 警告黄 |
| danger | `#F25056` | 危险红 |

噪点肌理：双层 `radial-gradient(rgba(255,255,255,0.012) 1px, transparent 1px), radial-gradient(rgba(120,150,190,0.01) 1px, transparent 1px)`，配合 `background-size: 3px 3px`。

### 3. 玻璃卡面配方（卡片/弹窗/菜单/任务瓷砖统一）

- `background-color: var(--al-card, rgba(22,28,40,0.92))`
- `background-image: linear-gradient(180deg, rgba(255,255,255,0.07), rgba(255,255,255,0) 38%), 噪点层`
- `background-size: 100% 100%, 3px 3px; background-repeat: no-repeat, repeat`
- `backdrop-filter: blur(var(--al-blur, 12px))`（双写 `-webkit-`）
- `border: 1px solid var(--al-border, rgba(120,140,170,0.18))`
- `border-radius: var(--al-radius, 12px)`
- `box-shadow: inset 0 1px 0 rgba(255,255,255,0.04~0.05), 0 16px 48px rgba(5,8,12,0.6)`（小卡可 0 8px 24px rgba(5,8,12,0.5)）
- `color: var(--al-text, #E6E9EF)`

遮罩层：`rgba(9,12,17,0.72)` + `backdrop-filter: blur(6px)` 双写。
**历史列表容器**（统计表格/异常列表）不套卡面：透明底 + blur(12px) 双写 + 1px 细边 + 圆角 + 仅外阴影。

### 4. 组件视觉约定

1. **固定悬浮状态条/收起条**：半透黑 `rgba(6,8,12,0.82)`（**字面量**，防宿主同名变量覆盖成浅色）+ 玻璃高光/噪点 + blur(12px) 双写 + 亮字回退 + 1px 细边 + 内高光 0.05 / 外阴影 `0 8px 24px rgba(5,8,12,0.5)`；状态点 accent 脉冲；错误/告警态**仅改边框色 + 阴影**，不覆盖深色底。
2. **模块卡片/任务瓷砖/历史卡片**：深色玻璃卡面 + 顶部高光渐变；只保留左侧色条（`border-left: 3px solid <挂档色>`）不覆盖深色底；hover 边框提亮 borderHi。
3. **详情/信息弹窗**：深色玻璃卡 + `max-height: 86vh` + 隐藏右侧滚动条（保留滚动）。
4. **Tab**：胶囊式 + 底部荧光绿指示条；**按钮**：默认 `1px solid var(--al-border)` / 主按钮 accent（黑字 `#0A0E13`）；一键筛选类按钮（如「全部」）= 黑底白字、无边框、无紫色光环；**输入框**：bgDeep 底 + border 边 + focus info 边 + 2px 光环；**checkbox**：`accent-color: var(--al-accent)`；**菜单**：`rgba(24,30,42,0.92)` 底 + 卡面配方 + item hover violet 0.14 底 + text 字。
5. **标题栏/横幅**：深色实底 `--al-bgDeep`；进度条荧光绿 accent；状态灯：绿=正常（accent）/ 蓝=运行中（info）/ 橙=有告警（warn/orange）/ 红=异常（danger）。
6. **滚动区**（模块网格/卡片体/弹窗体/列表容器）隐藏右侧滚动条但保留滚动。

### 5. 语义色映射（确定性派生）

- 重要度 ≥80 红 / ≥60 橙 / <60 蓝 / 不可解析一律蓝（`#F25056 / #FF9E57 / #64B5F6`）；卡片左侧色条与筛色块同映射。
- 徽章：小尺寸半透胶囊，等级/文字色 + `rgba(色,0.12~0.20)` 底 + `rgba(色,0.25~0.40)` 边；数字加粗 tabular-nums。
- 状态灯：normal=accent / running=info / alert=warn / error=danger / 未知兜底 text3。

## 六、TDD 与单测要求（先红后绿，拒绝伪测试）

单元测试最低断言集（`node --test`，纯函数无 DOM）：

1. **玻璃卡面配方完整性**：瓷砖/卡片 skin 输出同时含 `background-color: var(--al-card, rgba(22,28,40,0.92)`、`radial-gradient` 噪点、`background-size: 100% 100%, 3px 3px`、`backdrop-filter: blur(` 与 `-webkit-backdrop-filter: blur(`、`border: 1px solid var(--al-border`、`border-radius: var(--al-radius, 12px)`、inset 高光与外部阴影；缺少任意一项 → 红。
2. **历史列表容器防误用**：统计表格/异常列表输出**不含** `linear-gradient(180deg, rgba(255,255,255,0.07)`（卡面高光）且含 `background: transparent`/无衬底背景声明 + blur 双写 → 防二次网格感回归。
3. **状态灯映射边界**：normal/accent、running/info、alert/warn、error/danger、`''`/`null`/`undefined`/未知字符串 → text3 兜底；状态字符串大小写混合（`'Running'`）→ 归一化后 info，不抛错。
4. **重要度映射边界**：`80`→红、`79.99`→橙、`60`→橙、`59.99`→蓝、`0`、`-1`（越界下限）、`101`（越界上限）、`NaN`→蓝、`'85'`（数字字符串）→红、`''`→蓝、`null`→蓝。
5. **硬编码色值扫描**：对皮肤生成器全部输出做 `#[0-9a-fA-F]{6}` 扫描，断言结果 ⊆ 白名单集合（`#FFFFFF`、`#0A0E13`）；发现任何白名单外 hex → 红。
6. **收起条底色铁律**：状态条输出含字面量 `rgba(6,8,12,0.82)`（防宿主变量覆盖），不依赖 `var(--al-*)` 解析。
7. **滚动隐藏**：滚动规则输出含 `scrollbar-width: none` 与 `::-webkit-scrollbar { display: none; }`。
8. **tabular-nums**：涉及数字的容器规则含 `font-variant-numeric: tabular-nums`。

伪测试标准（以下一律判无效，必须返工）：光标未运行、断言恒真、只测成功路径无数值/空值/越界输入、依赖 DOM 却用极浅断言。

2. 瓷砖（码表/历史日K/快照us/sh/sz/bj/hk）：玻璃卡面、左侧状态色条（待命中=蓝、运行中=蓝/绿、异常=红，按数据 status 字段确定性派生）、hover 边框提亮；
3. 「继续/暂停」：主/次操作样式语义清晰，hover 与按压有明确反馈；
4. 进度条 accent 荧光绿，进度数字 tabular-nums；完成状态不再闪烁；
5. 上一轮统计表格：透明容器 + 结果列语义色（成功=绿/失败=红/进行中=蓝），数字等宽；
6. 历史异常列表：透明容器 + 严重级徽章语义色（高危=红/重要=橙/一般=蓝），滚动隐藏条；
7. 收起态单行条（360×36）：半透黑磨砂、状态点脉冲、深底亮字，任意宿主页面可读；
8. 全部滚动区域（网格/卡体/弹窗/列表）隐藏滚动条但可滚动；
9. Ctrl+F5 强刷后：所有面板、弹窗、悬浮条、滚动区正常交互，无布局错位；
10. 截取改造前后同场景截图各一张，作为验收比对底稿。

## 十、风险清单（完成时附带输出）

1. **令牌变量失效兜底**：任何 `var(--al-x)` 未带字面量兜底 → 宿主页面变量缺失时落空/变白；以单测 1 与 6 卡关；
2. **宿主变量污染**：收起条/悬浮条底色必须字面量 `rgba(6,8,12,0.82)`，防宿主同名 `--al-accent` 等覆盖成浅色；
3. **二次网格感**：任务瓷砖不得叠加 3px 噪点网格（仅高光渐变），列表容器不得套卡面配方——单测 2 卡关；
4. **性能**：禁止持续变换动画/大面积动画；仅 hover/按压过渡与既有脉冲动画；
5. **对比度**：深底上 text3 弱文字仅用于辅助信息，主信息一律 text/text2；
6. **版本漂移**：生产代码库与本地 checkout 不一致（图2 组件本地未检出）——所有改动必须在生产代码库验证，禁止以本地旧代码为准。
